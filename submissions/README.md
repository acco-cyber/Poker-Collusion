# Submission CSVs

The actual submission CSVs are generated by running the notebook:
- `notebooks/kaggle_notebook_day2.py` on Kaggle, or
- `notebooks/kaggle_notebook_day2_local.py` locally

After running, you'll find 5 CSVs:
- submission_01_user_baseline.csv
- submission_02_hybrid_3plus2.csv
- submission_03_hybrid_4plus1.csv
- submission_04_hybrid_2plus3.csv
- submission_05_passive_soft_play.csv

Each is ~14MB (112,540 rows × 8 columns).

These are NOT included in this repo because:
1. They're generated from competition data (license restrictions)
2. They're large (14MB each)
3. They change based on the user's previous submission

## To Generate

```bash
# On Kaggle (recommended):
# 1. Add competition dataset as input
# 2. Add user's previous submission as input
# 3. Upload notebooks/kaggle_notebook_day2.py
# 4. Run all cells
# 5. Download 5 CSVs from /kaggle/working/

# Or locally:
python notebooks/kaggle_notebook_day2_local.py
# Files saved to /home/z/my-project/kaggle/runs/day2/
```
