## Day 2 Strategy (2026-09-18)

This repo contains a single Kaggle notebook that generates **5 different submission CSVs**
from 5 different evidence-selection strategies. The user can submit them one-by-one
(5 submissions available tomorrow) to find the best one.

### The 5 Strategies

| # | File | Strategy | Hypothesis |
|---|------|----------|------------|
| 1 | `submission_01_user_baseline.csv` | User's original (sanity check) | Should reproduce 0.83065 |
| 2 | `submission_02_hybrid_3plus2.csv` | User top-3 + chip top-2 | Yesterday's 0.81486 |
| 3 | `submission_03_hybrid_4plus1.csv` | User top-4 + chip top-1 | More conservative — minimal change |
| 4 | `submission_04_hybrid_2plus3.csv` | User top-2 + chip top-3 | More aggressive — bet harder on chip signal |
| 5 | `submission_05_passive_soft_play.csv` | Replace evidence ONLY for soft_play pairs | Targeted fix for one behavior family |

### Common Pattern

All strategies:
- **Keep user's `risk_score`** unchanged (preserves pair_ap signal)
- **Keep user's `predicted_behavior`** unchanged (preserves behavior_map signal)
- **Vary only the 5 `evidence_hand_*` columns**

This isolates the evidence selection variable so we can learn what works.

## How to Run on Kaggle (recommended)

1. **Add competition dataset as input**:
   - In your Kaggle notebook, click "Add Input" → search "Detect Suspicious Value Transfers in Poker"

2. **Add user's previous submission as input**:
   - Click "Add Input" → search "kragglenote2forwork/poker-collusion-pu-aware-evidence-ranker"
   - This adds the user's 0.83065 submission as a dataset

3. **Upload `notebooks/kaggle_notebook_day2.py`** to a new Kaggle notebook

4. **Run all cells** — takes ~5 min on Kaggle (16GB RAM)

5. **Download the 5 submission CSVs** from `/kaggle/working/`

6. **Submit each one separately** via:
   ```bash
   kaggle competitions submit detect-suspicious-value-transfers-in-poker      -f submission_01_user_baseline.csv -m "Day 2 strategy 1: user baseline sanity check"
   ```
